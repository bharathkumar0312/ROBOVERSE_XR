# ◈ ROBOVERSE XR
### AI-Powered Robotics Digital Twin with Augmented Reality & Virtual Reality


**Bridging Robotics, Extended Reality and Intelligent Automation**

---

## 🚀 Overview

ROBOVERSE XR is an interactive 3D robotics digital twin platform that integrates Augmented Reality (AR), Virtual Reality (VR), and robotics simulation to create an immersive environment for robotic visualization, control and monitoring.

The project aims to demonstrate how Extended Reality (XR) can improve the way engineers interact with robotic systems by providing real-time visual feedback, interactive joint manipulation, simulated sensor monitoring and predictive fault alerts.

Using Three.js and WebXR technologies, ROBOVERSE XR creates a browser-based industrial robotics environment where users can interact with a virtual robotic arm, monitor operating parameters and explore immersive simulation experiences.

## 🎯 Project Objectives

- Develop an interactive 3D robotic digital twin.
- Integrate AR and VR technologies into robotics simulation.
- Enable real-time manipulation of robotic joints.
- Visualize robotic components through spatial information overlays.

- Explore the potential of XR in industrial automation and robotics education.

## 🏗️ System Architecture

ROBOVERSE XR follows a modular browser-based architecture:

1. **User Interface Layer:** Provides the interactive control dashboard and monitoring interface.
2. **3D Visualization Layer:** Uses Three.js and WebGL to render the robotic environment.
3. **Robotics Simulation Layer:** Handles robotic joint movements and automated motion sequences.
4. **XR Integration Layer:** Uses WebXR for compatible immersive AR and VR experiences.
5. **Monitoring Layer:** Displays simulated sensor parameters and system status.
6. **Fault Monitoring Layer:** Evaluates simulated operating conditions and generates fault alerts.

## ⚙️ Installation and Setup

### Prerequisites

- Visual Studio Code
- Google Chrome or another compatible browser
- Node.js (optional for a local development server)
- Live Server VS Code extension

### Step 1: Clone the Repository

```bash
git clone https://github.com/bharathkumar0312/ROBOVERSE_XR.git
```

### Step 2: Navigate to the Project

```bash
cd ROBOVERSE_XR
```

### Step 3: Open in VS Code

```bash
code .
```

### Step 4: Run the Application

Open `index.html` using the Live Server extension.

Alternatively, use a local HTTP server:

```bash
python -m http.server 8000
```

Open your browser:

```text
http://localhost:8000
```

Internet access is required for the CDN-hosted Three.js dependencies.

## 🖥️ How to Use

1. Launch ROBOVERSE XR in your browser.
2. Explore the 3D robotic environment using mouse controls.
3. Adjust robotic joint angles using the interactive controls.
4. Activate automatic movement to observe robotic motion.
5. Enable or disable AR-style information overlays.
6. Monitor temperature, motor speed and battery levels.
7. Inject an overheating fault to observe the warning system.
8. Reset the system to restore normal simulated operating conditions.
9. Connect a compatible XR headset to explore immersive features.
